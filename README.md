# Khaled Hasan Munna — Cinematic Portfolio

A responsive editorial-style portfolio inspired by the broad design language and interaction patterns visible in the supplied Kunal Singh website reference (sticky pill navigation, cinematic hero, reel showcase, editorial philosophy, project filtering, marquee, production pipeline and contact section). This is an original implementation and does not reuse Kunal Singh's code, images, logos or exact copy.

## Files
- `index.html` — content and page structure
- `styles.css` — responsive layout, light/dark theme and motion effects
- `script.js` — loader, sticky navigation, mobile menu, theme toggle, scroll reveal and project filters

## Publish with GitHub Pages
1. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload all three files to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Your website will publish at `https://YOUR-GITHUB-USERNAME.github.io/`.

## Replace these placeholders before publishing
- Hero portrait: replace the `.portrait-placeholder` element in `index.html` with your approved portrait image.
- Showreel: replace the current reel placeholder link with an embedded YouTube/Vimeo player or your hosted showreel URL.
- Project covers: replace the gradient `.image-one` to `.image-six` backgrounds with your own approved project thumbnails.
- Project links: each project currently links to your existing Google Sites portfolio. Replace with the exact project video/page URLs.
- Verify every client/organization credit, role, project date and experience claim. The “10+ years” style metric is not asserted here; the experience block uses a cautious note.
- Add a direct CV PDF download link when the final CV is ready.

## Local preview
Open `index.html` in a browser or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.
