KHALED HASAN MUNNA — CINEMATIC PORTFOLIO

This is a rebuilt, responsive portfolio inspired by the broad cinematic/editorial approach of the reference site.
It does not copy the reference site's source code, text, images, or branding.

FILES
- index.html
- styles.css
- script.js

IMPORTANT PROFILE IMAGE
Keep your existing portrait image in the same folder as index.html and name it exactly:
profile.jpg

If your file is currently named profile.jpg.jpg, rename it to profile.jpg.

LOCAL PREVIEW
Open the folder in VS Code. You can use the Live Server extension, or simply open index.html in a browser.
The page is designed to remain scrollable even if JavaScript is disabled.

GITHUB PAGES UPDATE
1. Back up your current repository folder.
2. Replace index.html, styles.css and script.js with these files.
3. Keep profile.jpg in the repository root.
4. In GitHub Desktop, review the changes, Commit to main, then Push origin.
5. Wait for GitHub Pages to deploy, then hard-refresh the site with Ctrl+F5.

CONTENT
Professional roles, education, skills and training are based on the supplied CV. Project cards are experience areas and link to the portfolio homepage until individual project URLs are supplied.
